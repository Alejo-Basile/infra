## 10. Desviaciones respecto de `docs/S8/tasks/task-3.md`

1. El archivo de pesos es `infra/traefik/dynamic/routing.yml`, no
   `middlewares.yml`: S8-P1-02 movio el ruteo al file provider como fuente unica
   y `middlewares.yml` conserva solo middlewares. Editar `middlewares.yml`
   duplicaria `http.services` entre archivos del mismo provider.
2. Los hijos del `weighted` son `docv2` (estable) y `docv2-canary` (candidato),
   no `monolito@docker`/`doc-service@docker`: son servicios del file provider,
   no labels Docker, y el canary de despliegue no envia trafico v1 al monolito.
3. La medicion usa N=1000, el tamano de muestra que la propia tabla §7 fija para
   10 %. Para 1 % ese N sigue dando una banda ±3σ decisiva ([0,56, 19,44]) y
   permite distinguir 0 % de 1 %. El N=10000 es un recorrido de ~17 minutos por
   el rate limit (10 req/s); `--measure 10000` queda disponible.
4. La recarga se verifica por comportamiento en el access log (no hay API de
   Traefik expuesta: `/api/*` responde 404). El primer `docv2-canary@file` con
   peso 1 % aparece en la peticion 51, dentro de la ventana de 10 s.
