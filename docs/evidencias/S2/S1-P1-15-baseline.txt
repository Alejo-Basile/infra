# S1-P1-15 — Baseline de hardening de contenedores — evidencia (2026-11-06)

## Método
docker inspect con --format acotado a los 5 controles, sobre todos los
contenedores del proyecto Compose `infra` (running + exited, perfiles sentinel y
jobs de init incluidos). Se excluyen Config.Env y cualquier valor secreto.
Interpretación: User vacío = root; CapDrop vacío = sin caps dropped;
SecurityOpt vacío = sin no-new-privileges; Pids=0 = ilimitado.
