== NOTE ==
El key del rate limiter actual es global y estatico (rl:api-v2; ADR-0005 deja
la identidad por IP para S7). Por eso la prueba valida que un XFF falsificado
NO crea claves con la IP del atacante. El aislamiento de XFF se garantiza en
Traefik: trustedIPs compara contra el peer del socket; el peer Docker no esta
en 192.0.2.0/24, de modo que todo XFF entrante se descarta.
