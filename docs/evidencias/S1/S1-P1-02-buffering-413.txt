== S1-P1-02a — Buffering: body de 2MB rechazado en el edge (Traefik), sin llegar a doc-service ==
fecha: 2026-10-08T01:56:19Z

Config: middleware body-limit-1mb@file (infra/traefik/dynamic/middlewares.yml) sobre router docv2.

POST https://api.localhost:8543/api/v2/documents (body JSON 2MB, X-Correlation-Id: c-02a-buffering-1791424547) -> HTTP 413

Traza del access log de Traefik (JSON):
{
  "RouterName": "docv2@docker",
  "RequestMethod": "POST",
  "RequestPath": "/api/v2/documents",
  "DownstreamStatus": 413,
  "OriginStatus": 0,
  "OriginDuration": 0,
  "RequestContentSize": 0,
  "request_X-Correlation-Id": "c-02a-buffering-1791424547"
}

Interpretacion: DownstreamStatus=413 pero OriginStatus=0 y OriginDuration=0 -> Traefik corto la subida
en el edge por body-limit-1mb; el request NUNCA llego a doc-service (0 coincidencias del correlation
id en los logs de infra-doc-service-1). El buffering limita el costo de un DoS por payload gigante.
