=== S1-P1-02b EntityTooLarge desde MinIO ===
Fecha: 2026-10-08

head -c 30000000 /dev/urandom > /tmp/big.pdf

3a) Create declarando size_bytes=30000000 -> HTTP 400 doc-service
    "size_bytes excede el máximo permitido: 26214400 bytes"
    (validación servicio, NO EntityTooLarge)

3b) Create size_bytes=10485760 (válido) + body real 30MB -> HTTP 400 MinIO
    <Error><Code>EntityTooLarge</Code><Message>Your proposed upload exceeds the maximum allowed object size.</Message>
    Policy decodificada: ["content-length-range",1,26214400]
Objeto NO escrito (mc stat -> does not exist); conteo 10 -> 10; doc sigue PENDING_UPLOAD

ACLARACIÓN: "Declarar 30MB" se rechaza en create (400). La prueba real del tope es declarar válido y enviar 30MB.
