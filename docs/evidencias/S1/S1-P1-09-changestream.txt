Entorno: replica set `rs0` de un solo nodo (**PRIMARY**, `state=1`) en `infra-mongo-1`.
Usuario: `MONGO_APP_USER` (rol `readWrite` acotado a la base `documents`).
Colección: `documents` — sin validador (`options: {}`).

## Filtro del relay (SPEC §5.3)

```js
db.documents.watch(
  [{ $match: { operationType: "update", "fullDocument.status": "UPLOADED" } }],
  { fullDocument: "updateLookup", maxAwaitTimeMS: 500 }
)
```

## Método

Por cada corrida se inserta un documento `test-s1-09-N` en `PENDING_UPLOAD` (evento
`insert`, no matchea el filtro) y se mide `Date.now()` desde el `update` a `UPLOADED`
hasta que el cursor entrega el evento. 3 corridas. El documento de prueba se borra al
final de cada corrida.
